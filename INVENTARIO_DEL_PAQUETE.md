# Inventario de entrega

El archivo ZIP incluye:

- Código fuente completo de todas las páginas y componentes.
- Estilos globales y comportamiento responsive.
- Imágenes y recursos del directorio `public`.
- Dependencias bloqueadas en `package-lock.json`.
- Configuración de TypeScript, Vite, Vinext, Tailwind, ESLint y Cloudflare.
- Pruebas automáticas incluidas en el proyecto.
- Guía específica para Claude Code en `CLAUDE.md`.

No se incluyen `node_modules`, archivos temporales ni credenciales. Las dependencias se reconstruyen con `npm ci`.
